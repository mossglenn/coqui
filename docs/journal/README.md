# Journal

Working records: how the design got where it is, and what it stopped believing on the way.

**Nothing here is current.** Every document in this directory has been superseded by the
specifications in `../design/` — that is what it means to be in the journal. Read these when you
are about to *change* something and want to know what has already been tried and discarded. Do not
read them to find out what the model currently says.

Kept rather than deleted because the corrections are the expensive part. Several are
methodological and would otherwise be relearned.

| Entry | What it covers |
|---|---|
| `claims-model-history.md` | Superseded reasoning behind `../design/claims.md` — the seven-judgment list, the diagnostic-misconception cell, the cueing argument that proved too much, and three successive interaction budgets |
| `2026-08-claims-review.md` | The annotated-comment review pass: 23 decisions across seven threads, with the propagation record for each |

## Adding an entry

Date-prefix it (`YYYY-MM-`) if it records a dated pass; name it by subject if it accumulates.
Say at the top what it supersedes and where current truth lives.
